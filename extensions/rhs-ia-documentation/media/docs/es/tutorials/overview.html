Tutoriales

Los tutoriales practican el flujo de trabajo básico de RHS-IA con proyectos locales pequeños. Elige el tutorial de Jupyter Notebook para un análisis interactivo basado en celdas o el tutorial de Quarto para un documento ejecutable.

Antes de empezar, instala un intérprete compatible de Python o R y los paquetes necesarios para el ejemplo elegido. Trabaja en una carpeta nueva para mantener aislados los archivos generados y la configuración del entorno.

Cada tutorial termina con una comprobación en una sesión limpia para asegurarse de que el resultado se pueda reproducir.
