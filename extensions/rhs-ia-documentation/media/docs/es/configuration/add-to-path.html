Iniciador de línea de comandos

El iniciador de línea de comandos abre archivos y carpetas en RHS-IA desde un terminal. En RHS-IA, abre la Paleta de comandos y ejecuta Shell Command: Install ‘rhs-ia’ command in PATH cuando ese comando esté disponible para tu plataforma.

Después de instalarlo, ejecuta rhs-ia . para abrir la carpeta actual o rhs-ia path/to/file para abrir un archivo. Reinicia el terminal si ya estaba abierto para que reciba el PATH actualizado.

Si el comando del iniciador no está disponible, inicia RHS-IA normalmente y usa Archivo > Abrir carpeta.
