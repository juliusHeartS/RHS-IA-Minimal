Acerca de RHS-IA

RHS-IA es un entorno de desarrollo integrado centrado en el análisis de datos y la computación científica. Reúne la edición de código fuente, los terminales, el control de código fuente, los tiempos de ejecución de Python y R, los cuadernos, los documentos ejecutables, las variables, los gráficos y la exploración de datos en un mismo entorno de trabajo.

Esta guía incluida documenta el software RHS-IA disponible en la compilación actual. Las funciones proporcionadas por extensiones de terceros pueden tener documentación y condiciones de soporte independientes.

Consulta Atribución y licencia de la documentación para conocer la procedencia y las condiciones de reutilización de esta guía.
