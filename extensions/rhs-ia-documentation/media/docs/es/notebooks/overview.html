Cuadernos de Jupyter

Abre un archivo .ipynb para editar celdas Markdown y de código ejecutables. Selecciona un kernel que coincida con el lenguaje y el entorno del cuaderno; después ejecuta celdas individuales o el cuaderno completo.

El orden de ejecución importa porque un kernel de cuaderno conserva el estado. Reinicia el kernel y ejecuta todas las celdas antes de confiar en un resultado o compartir el archivo. La salida guardada de una celda puede diferir del estado actual del kernel.

RHS-IA incluye un editor de cuadernos de ciencia de datos y el editor heredado para compatibilidad.
