Inicio del intérprete

RHS-IA puede iniciar un tiempo de ejecución cuando la ejecución de código u otra función de lenguaje lo necesita. El inicio usa el intérprete seleccionado, el directorio del espacio de trabajo, las variables de entorno y los archivos de inicialización específicos del lenguaje.

Consola informa del progreso y los errores de inicio. Si un tiempo de ejecución no se inicia, confirma que el ejecutable todavía exista, pruébalo en un terminal e inspecciona el canal de salida correspondiente. Después, selecciona de nuevo el intérprete o reinicia la ventana.

El código de inicio no debería solicitar entrada interactiva del terminal porque la sesión de lenguaje puede inicializarse antes de que haya un indicador de consola disponible.
