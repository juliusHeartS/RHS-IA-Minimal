Reticulate

Reticulate permite que una sesión de R llame a Python. El entorno de Python seleccionado por reticulate es independiente del tiempo de ejecución de Python que RHS-IA pueda usar para archivos de Python independientes.

Configura el entorno de Python de reticulate antes de importar módulos de Python en R. Una vez que Python se ha inicializado dentro del proceso de R, cambiar de entorno normalmente requiere reiniciar R.

Al solucionar problemas, compara el ejecutable informado por reticulate con el entorno que pretendías usar y confirma que los paquetes de Python necesarios estén instalados allí.
