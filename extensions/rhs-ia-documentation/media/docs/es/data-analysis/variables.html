Variables

La vista Variables muestra los objetos de la sesión activa del tiempo de ejecución. Las entradas incluyen un nombre, un tipo y una representación compacta cuando el tiempo de ejecución puede proporcionar una.

Expande los objetos compatibles para inspeccionar sus elementos secundarios. Usa las acciones contextuales para ver datos tabulares, copiar valores o quitar objetos cuando estén disponibles. La vista se actualiza cuando el código crea y cambia variables.

Cambiar de sesión cambia el entorno mostrado. Trata la vista como una herramienta de inspección activa; el código fuente, no la lista de objetos de la sesión, es el registro reproducible de un análisis.
