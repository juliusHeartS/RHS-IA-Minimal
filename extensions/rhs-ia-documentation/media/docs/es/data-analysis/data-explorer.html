Data Explorer

Data Explorer abre objetos tabulares en un visor interactivo. Usa la acción Open in Data Explorer de un objeto desde Variables, un resultado de cuaderno u otra superficie compatible.

El visor combina una cuadrícula de datos, una barra de filtros y un panel de resumen. Ordenar y filtrar cambia la vista de los datos; no reescribe silenciosamente el objeto del tiempo de ejecución.

Los datos grandes o remotos pueden cargarse por páginas. Las operaciones disponibles y los resúmenes de tipos dependen del tiempo de ejecución del lenguaje y de su proveedor de Data Explorer.
