Panel de resumen de Data Explorer

El panel de resumen describe la columna seleccionada. Según su tipo, puede mostrar conteos, valores faltantes, rangos, distribuciones, frecuencias u otras estadísticas proporcionadas por el tiempo de ejecución.

Selecciona otra columna para actualizar el resumen. Los resultados pueden ser aproximados o estar limitados cuando el proveedor evita transferir un conjunto de datos grande completo.

Usa el panel para detectar problemas de calidad y distribuciones inusuales; después calcula y registra las estadísticas definitivas en el código del proyecto.
