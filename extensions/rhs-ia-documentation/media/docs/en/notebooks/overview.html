Jupyter Notebooks

Open an .ipynb file to edit Markdown and executable code cells. Select a kernel that matches the notebook language and environment, then run individual cells or the entire notebook.

Execution order matters because a notebook kernel keeps state. Restart the kernel and run all cells before relying on a result or sharing the file. Saved cell output can differ from the current kernel state.

RHS-IA includes a data-science notebook editor and the legacy editor for compatibility.
