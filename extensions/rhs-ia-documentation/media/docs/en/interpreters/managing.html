Managing Interpreters

An interpreter identifies the Python or R installation used to start a runtime. Use the interpreter selector or Command Palette to view discovered installations and select one for the workspace.

RHS-IA remembers suitable selections in workspace state. A newly created virtual environment or newly installed runtime may require a refresh or window reload before it appears.

Choose project-local environments when possible, verify the displayed executable path, and restart active sessions after changing interpreters. Continue with Python Installations or R Installations.
