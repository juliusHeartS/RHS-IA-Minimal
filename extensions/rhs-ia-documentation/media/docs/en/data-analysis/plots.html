Plots

Plots produced by a supported Python or R runtime appear in the Plots view. Use the history controls to move among plots created in the current session.

Resize the view to redraw responsive plots. Available actions can include zoom, open in a larger editor, copy, and export; exact formats depend on the plot provider.

For repeatable output, create and save figures from source code with explicit dimensions and file formats. Session plot history is temporary and ends with the runtime session.
