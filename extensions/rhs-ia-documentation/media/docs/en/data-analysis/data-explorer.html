Data Explorer

Data Explorer opens tabular objects in an interactive viewer. Use an object’s Open in Data Explorer action from Variables, a notebook result, or another supported surface.

The viewer combines a data grid, filter bar, and summary panel. Sorting and filtering change the view of the data; they do not silently rewrite the runtime object.

Large or remote data may be loaded in pages. Available operations and type summaries depend on the language runtime and its data-explorer provider.
