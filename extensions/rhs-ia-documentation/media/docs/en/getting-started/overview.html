Getting Started

RHS-IA combines an editor, terminal, source control, language runtimes, and data-science tools in one workspace. Open a folder for an existing project, or use File > New Folder to begin from a template.

First session

Install or select a Python or R interpreter, open a source file, and run code with the editor’s Run action. Output appears in the Console; objects, plots, and data open in their dedicated views.

Use View > Command Palette whenever you know an action but not its location. Open this guide from the Documentation icon in the Auxiliary Bar or with Cmd/Ctrl+Shift+H.

Next steps

Learn the workspace layout, configure keyboard shortcuts, or follow a tutorial.
