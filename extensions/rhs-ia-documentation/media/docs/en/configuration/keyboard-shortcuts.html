Keyboard Shortcuts

Open Keyboard Shortcuts from the Command Palette to search actions, inspect conflicts, and change bindings. Select the edit icon beside a command, enter the new key combination, and press Enter.

RHS-IA inherits familiar editor shortcuts and adds data-science actions. Cmd/Ctrl+Shift+P opens the Command Palette, Cmd/Ctrl+` toggles the terminal, and Cmd/Ctrl+Shift+H opens Documentation. On macOS, Cmd commonly replaces Ctrl.

Changes are stored in your user keybindings. Use the context-menu reset action to restore a command’s default.
