Git

RHS-IA includes Git source-control integration. Install Git on the computer, open a repository folder, and select Source Control from the Activity Bar.

Changed files appear by repository. Select a file to review its diff, stage selected changes with the plus action, enter a commit message, and choose Commit. Fetch, pull, push, branch, clone, and repository initialization actions are available from the Source Control menu and Command Palette.

RHS-IA uses the Git identity and credentials configured on your system. Confirm the active branch and staged files before committing.
