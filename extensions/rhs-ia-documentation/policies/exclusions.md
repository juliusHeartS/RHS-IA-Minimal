# Exclusion Policy

The following content is excluded from the RHS-IA software documentation:

- Posit Assistant and Positron Assistant;
- Databot and other upstream AI features;
- Assistant providers, completions, chat, context, instructions, configuration, privacy, troubleshooting, tutorials, screenshots, and embedded references;
- RHS-IA Agent documentation until the Agent implementation and its documentation contract are ready;
- Updating Positron, update channels, and Posit release infrastructure;
- Posit Publisher, “Publish your work,” and Publisher-specific workflows;
- migration guides from VS Code or RStudio;
- Posit-specific policies or infrastructure presented as RHS-IA behavior;
- public-site marketing, download, newsletter, and analytics material.

Exclusion is semantic. A retained page containing an excluded reference remains blocked until the reference is removed or the page is reclassified.
