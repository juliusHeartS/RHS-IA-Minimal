# RHS-IA Documentation Content Policy

The documentation describes behavior that can be verified in RHS-IA. The copied Positron website is reference material, not authoritative RHS-IA behavior.

Each upstream page has one disposition: `KEEP`, `ADAPT`, `REWRITE`, `REMOVE`, or `REVIEW`. Pages in `REVIEW` cannot enter a production build. A global replacement of “Positron” with “RHS-IA” is prohibited.

English will become the canonical documentation source. Spanish translations will be produced from verified RHS-IA English pages, never directly from upstream material.

Generated files under `media/docs/` are build output and must not be edited manually.
