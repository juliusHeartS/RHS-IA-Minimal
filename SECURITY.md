# RHS-IA security reporting

RHS-IA is a fork of Positron. The Posit Software security policy, response-time commitments, PGP key, and bug-bounty statements previously copied into this file do not constitute commitments or a reporting channel for this fork.

Do not publish a suspected RHS-IA vulnerability, exploit details, credentials, or private data in a public issue. Contact the RHS-IA repository owners through an existing private PAHO or repository-maintainer channel. A dedicated public security-reporting address for RHS-IA has not been established. Maintainers should add a verified private reporting channel before distributing a release.

For a vulnerability that also affects unmodified upstream Positron, consult [Posit's upstream security policy](https://github.com/posit-dev/positron/security/policy). For a Code OSS or other dependency vulnerability, use that project's reporting policy. Include the affected RHS-IA commit, platform, reproduction steps, and impact when reporting privately.
